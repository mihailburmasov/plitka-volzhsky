# «Ровный шов» — сайт плиточника в Волжском

Сайт мастера-плиточника Евгения (Волжский, Волгоградская область): укладка плитки и керамогранита, запил 45°, ниши и полки, столешницы и фартуки из керамогранита, ванная под ключ, сопутствующие работы.

Статический сайт, его собирает Node-генератор без фреймворков. Единственная зависимость — `sharp` (фото, иконки, OG-картинка).

## Команды

```bash
npm install
npm run images      # фото из _source/ → src/assets/img/*.webp и src/data/images.json (папка _source не в git)
npm run build       # превью → docs/ (GitHub Pages, noindex, Disallow: /, без Метрики)
npm run build:prod  # боевая сборка → dist/; НЕ собирается, пока в данных есть todo или draft
npm run serve       # превью локально: http://localhost:8091/plitka-volzhsky/
```

## Где что лежит

| Путь | Что |
|---|---|
| `src/data/company.json` | Все факты: название, телефон, MAX, e-mail, часы, оператор ПДн, домен, Метрика, адрес приёма заявок (`leadEndpoint`). Больше нигде не дублировать. `{"todo": "..."}` — данных от клиента пока нет. |
| `src/pages/services.mjs` | Шесть услуг: тексты, фото, FAQ. Блоки `draft(...)` — тексты студии, их должен подтвердить мастер. |
| `src/pages/misc.mjs` | Главная (квиз «Рассчитать стоимость», FAQ), работы, контакты, политика, 404. |
| `src/lib/ui.mjs` | Layout, шапка, подвал, JSON-LD, todo-бейджи. |
| `src/lib/svg.mjs` | Схемы (запил 45°, ниша, скрытый люк) и иконки. |
| `tools/curation.mjs` | Какие фото взяты и с какими подписями. `client` — работы мастера, `stock` — временные иллюстрации с Wikimedia Commons (подпись с автором и лицензией выводится автоматически). |

## Заявки

Пока `leadEndpoint` в `company.json` равен `null`, форма честно отвечает: «Это демо-версия, звоните или пишите в MAX». Когда появится обработчик (PHP на хостинге, Telegram-бот и т. п.), пропишите его адрес в `leadEndpoint`. Форма отправит туда POST с JSON: `task, area, extra, when, name, phone, comment, consent, page`.
